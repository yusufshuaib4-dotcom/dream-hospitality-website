# Dream Hospitality Sdn. Bhd. website

Static site (HTML/CSS/JS) hosted on GitHub Pages.

## Pages
`index.html`, `products.html`, `consultancy.html`, `about.html`, `contact.html`, plus `privacy-notice.html` (draft, noindex, unlinked until approved) and `404.html`.

## Editing
The five main pages and `sitemap.xml` are generated by `_build/build.py`, which holds the shared head, header and footer and each page's content. Edit content there, then run:

```
python3 _build/build.py
```

`_build/` is not published (GitHub Pages skips folders starting with `_`). `privacy-notice.html` and `404.html` are edited directly.

## Placeholders
Search for `PLACEHOLDER` in the code for content waiting on the company (logo, contact email/phone, enquiry form, team, launch details). The site URL is the interim github.io address: update `SITE` in `_build/build.py`, `robots.txt` and the base path in `404.html` when the domain is set.
